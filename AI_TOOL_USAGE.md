# AI Tool Usage

For this project, I used a few AI tools at different stages of the development process.

* **surf ai** — I used surf.ai primarily for research and exploration after receiving the assignment. I researched the existing approach, understood how comparable systems work, explored possible architectures, and identified an appropriate implementation strategy for the project.
* **Kiro** — I used Kiro for the actual coding and implementation of the project.
* **Antigravity** — I also used Antigravity as a coding assistant during development to help with implementation and development tasks.

These were the only AI tools I used for this project. I did not use any other AI coding or development tools.
